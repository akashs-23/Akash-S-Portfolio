---

## ✨ What makes this different

Not a typical portfolio. You **explore** it.

A fully interactive 3D island world built with Three.js — drag to orbit, discover projects as you go, with day/night mode and animated characters.

---

## 🚀 Features

- **3D World** — Orbit a living island with animated models (cyclist, robot, Doraemon, stage, scooter & more)
- **Scroll-triggered popups** — Projects and messages appear as you explore
- **Day / Night mode** — Auto-detects your local time
- **About page** — Skills marquee, profile card, journey timeline, project gallery
- **Contact page** — WhatsApp, Email & Call with one click
